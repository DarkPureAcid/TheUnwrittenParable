## Development Notes

### Mod Features
- Client-side only narrator mod
- 6 narrator personalities (Stanley, Nigel, Malcolm, Edgar, Chester, Reginald)
- Multiplayer narrators (Notch, Herobrine, Chuck Norris)
- Title-based message display
- Sound effects
- Language support

### Commands
- `/narrator info` - Show current narrator
- `/narrator test <1-6>` - Test message (respects cooldown)
- `/narrator broadcast <1-6>` - Test message (bypasses cooldown)
- `/narrator help` - Show help

### Technical Details
- Forge 1.20.1
- Client-side only
- Uses Minecraft's translation system
- JSON config file for data storage
